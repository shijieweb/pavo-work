一、状态枚举（中文 5 态 + 阻塞旁路）

状态含义在途？
待办已建卡未开工否
进行中正在执行是
待验证产出待独立验证（对齐验收链）是
已验证验证通过待收尾是
完成已闭环否
阻塞卡点挂起（旁路态，可提交）否

在途统计口径（check_wip / /ext/status）= 进行中 + 待验证 + 已验证。

二、优先级枚举

优先级排序
紧急0（最高）
高1

三、服务端校验规则（非法 → 400）

字段规则违规响应
title必填，非空字符串{"error":"title 不能为空"}
priority∈ {紧急,高,中,低}；缺省 中{"error":"priority 非法，允许: 紧急/高/中/低"}
status∈ 5 态+阻塞；缺省 待办{"error":"status 非法，允许: 待办/进行中/待验证/已验证/完成/阻塞"}

POST /api/tasks 全量校验；PUT /api/tasks/<id> 仅校验请求中出现的字段（部分更新）。校验失败不写库、不记审计。

说明：外部指导 API（/ext/*）免鉴权直达；看板写接口（POST/PUT/DELETE）须带 X-Board-Token（经 8787 代理自动注入）。

五、curl 示例

5.1 本地写（带 X-Agent + X-Board-Token）

curl.exe -H "X-Agent: 阿编" -H "X-Board-Token: <TOKEN>" -X POST http://127.0.0.1:8788/api/tasks \
  -H "Content-Type: application/json" \
  -d "{\"project_id\":19,\"title\":\"新任务\",\"priority\":\"高\",\"status\":\"待办\"}"

5.2 本地读（GET 免 token）

curl.exe "http://127.0.0.1:8788/api/tasks?project_id=19"

5.3 经网关看板路径（代理自动注入令牌）

curl.exe -H "X-Agent: 阿编" "http://127.0.0.1:8787/board/api/tasks?project_id=19"

5.4 外部指导（/ext 免鉴权）

curl.exe "http://127.0.0.1:8787/ext/status"
curl.exe -X POST http://127.0.0.1:8787/ext/notes -H "Content-Type: application/json" \
  -d "{\"project_id\":19,\"text\":\"远程指导留言\"}"

令牌来源：shared_board/.env 的 BOARD_TOKEN（首次启动自动生成并持久化）。

六、身份与规则

规则说明
X-Agent 身份头带身份头的读写会记在线状态与审计；不带 = 视为「老板」全权
owner 写锁写接口只能改 owner==自己 的项目/任务；改他人 → 403（老板豁免）
审计自动记带 X-Agent 的写操作自动记一条审计（谁/何时/动作/目标）
外部 /ext只读 + 留言（POST /ext/notes），无鉴权直达（老板决策，商用前再评估）
本页即接入规范载体（不另造 md 重复文档）。规则以服务端为准：非法输入会被 400 拒绝，请按枚举提交。
