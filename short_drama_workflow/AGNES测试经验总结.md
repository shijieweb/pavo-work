## 三、5 条强制规则 × 管线落实对照

| # | 用户规则 | 管线实现点 | 验证方式 |
|---|---|---|---|
| 1 | 严格区分**对白 / 独白**音频与口型 | `scene_type` 分流：`dialogue_*` → `CHINESE_SPEECH_RULE`；`monologue` → `MOUTH_STILL_RULE` + negative 双保险 | 代码层强制（按镜注入） |
| 2 | 对话：嘴唇自然开合、口型同步 | 对话镜 prompt 含 `engaged in conversation, listening and reacting…` + 中文闭唇小幅度口型 | 视觉 QA 成片 |
| 3 | 独白：嘴唇紧闭、零开口，仅眼神微表情 | `mouth_still=True` + 首帧锚点 `lips closed` + negative（`open mouth, talking, lip sync…`） | 视觉 QA（已注入） |
| 4 | 运镜顺滑、转场自然无割裂 | 场景类型预设自动选运镜；B 轮 3 镜 ffmpeg 淡入淡出拼接 | 已满足 |
| 5 | 穿搭/场景/光影统一、不突变 | 身份令牌冻结 + 设定稿 img2img 渲染首帧锁脸 + **SSIM 闸门（<0.40 自动重生成）** | SSIM 数值（0.8+） |

> 一致性铁律：AGNES 不支持 seed，靠「令牌逐字复用 + 设定稿图生视频锁脸」；首帧图即成片 frame0。

## 四、踩坑与修复（关键经验）

**Bug：正反打展开后成片下载失败**
- 症状：`download skip: Unknown format code 'd' for object of type 'str'`
- 根因：`novel_to_video.py` 里 `f"clip_{sid:02d}.mp4"`，正反打把单镜展开成 `sid="0.0"/"0.1"`（字符串），对字符串用 `:02d` 直接崩 → 首跑 round A 未存盘。
- 修复：`sid_s = str(sid).replace(".", "_")` → `clip_0_0.mp4` / `clip_0_1.mp4`。**对所有正反打场景生效**。
- 教训：凡是「单镜→多镜展开」的脚本，sid 必为字符串，命名格式串不能用整数限定符。

## 五、仍依赖人工视觉 QA 的环节

1. **口型真实开合**：管线只注入口型节奏约束，闭唇/张合的「像不像」需人眼确认。
2. **独白真闭唇**：`mouth_still` 是概率性约束，偶发仍轻微动嘴，需逐镜抽检。
3. **独白分段切换**：若同一镜内「对话↔独白」来回切，需明确分段策略（切特写闪回 / 镜内 `mouth_still` 分段），按台词节奏定。
4. **超长镜变形**：≥10s / ≥200 帧易背景漂移、尾帧嘴锁不住 → 优先拆 3–5s 短镜缝合。
5. **合规标识**：成片须叠「本片含 AI 生成内容」显式标识 + 元数据隐式标识，否则下架。

## 六、复用到新场景的标准动作（套模板填空）

1. 改 `characters`：每角色写**外貌 + 衣着锚点**（如「米白针织衫 / 深灰西装」），全角色都进字典（对话另一方只文本描述会掉脸）。
2. 改 `shots`：填 `text` / `scene_type` / `speaker` / `eye_line`（正反打左右交替）/ 独白镜加 `"mouth_still": true`。
3. 跑对应测试脚本（或 `novel_to_video.run(plan=..., shot_reverse=True/False)`）。
4. 查 SSIM 报告 + 下载成片，做视觉 QA。
5. 套用你的「分镜头填写模板」即可，无需重写管线。

## 七、成本与速率红线

- 视频 **RPM=5**；Token Plan 限量 **500 秒/天** → 创建按每批 5 个、批间隔 ≥12s。
- 视频异步：创建后必须轮询 `video_id`；`429/503` 指数退避自动重试（多密钥池可放大吞吐）。
- 单部投资额 <30 万 → 「其他类」AI 微短剧，免总局备案（仅平台备案 + 标识）。
