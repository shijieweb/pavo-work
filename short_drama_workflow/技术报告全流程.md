## 3️⃣ 资产生成路径

1. **参考图** → `scripts/storyboard/ep01_storyboard.json` 中 `references` → 自动下载至 `assets/references/`（由 server 启动时回写）  
2. **配音** → `generate_audio_real()` 用 MiniMax 多角色 TTS（或 gTTS 后备）生成 `assets/audio/shotXXX.mp3`  
3. **统一写回** → 产生的 `asset_image`、`asset_audio` 自动回填到原始 `shot` 字段，供前端 Studio 预览  

> **示例**  
> - 参考图 `newbie_village` → `assets/references/newbie_village.png`  
> - 配音 `male_lead` → `assets/audio/shot003.mp3`

## 4️⃣ 语音‑MiniMax 适配细节

| 参数 | 说明 |
|------|------|
| **voice_id** | `storyboard.json` 中的 `voice_roles.xxx.voice_id`（如 `female-shaonv`、`male-qn-qingse`），直接映射 MiniMax 声音 |
| **文本长度** | 单段 ≤ 4000 字符，超出会自动截断 |
| **回退方案** | 若所有 MiniMax 接口返回 404/2013，**自动切换到 gTTS**（生成占位音频） |
| **音频属性** | `sample_rate=32000, format=mp3, bitrate=128000`（可在 `audio_setting` 中配置） |
| **重要提醒** | 老板MiniMax Key 目前仅在 **test（sandbox）** 环境，实际使用要等平台开放正式 TTS 权限后方可正式切换 |

## 4️⃣ 关键实现代码片段（server.py）

```python
# ---------- audio generation ----------
def generate_audio_real():
    tts_mod = _load_minimax_tts()
    if tts_mod is None:
        return {"ok": False,
                "note": "MiniMax TTS 客户端加载失败（需检查 .env 或平台权限）"}

    out_dir = os.path.join(HERE, "assets", "audio")
    os.makedirs(out_dir, exist_ok=True)
    ok_list, fail_list = [], []

    for s in SPEC.get("shots", []):
        text = s.get("subtitle", "")
        if not text:
            continue
        voice_id = _voice_for_shot(s)               # 从 storyboard 中读取
        fn = os.path.join(out_dir, f"shot{s['id']:03d}.mp3")
        try:
            tts_mod.tts(text, voice_id=voice_id, out_path=fn)
            s["asset_audio"] = f"assets/audio/shot{s['id']:03d}.mp3"
            ok_list.append(s["id"])
        except Exception as e:
            fail_list.append({"id": s["id"], "err": str(e)})
    return {"ok": True,
            "output": "assets/audio/shot_NNN.mp3",
            "voices": ok_list,
            "failed": fail_list}
```
