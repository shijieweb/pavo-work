# Agnes Image 2.1 Flash 多图合成测试报告

> 测试时间：2026-08-12
> 测试人：老师
> 模型：agnes-image-2.1-flash
> 端点：POST https://apihub.agnes-ai.cn/v1/images/generations

## 一、测试目标

验证 Agnes Image 2.1 Flash 的「多图合成」功能：
1. 是否支持 3 张图输入？
2. 是否支持 4 张图？
3. 多图合成的质量如何？能否替代连环图生图？
4. 多角色融合效果如何？

## 四、关键发现

### 1. API 支持能力

- **2~4张图均支持**，无硬性限制
- 3张图耗时约25s，4张图耗时72s（接近3倍）
- **3张图是性价比最优解**

### 2. 多图合成的优势

- **场景融合好**：场景布局、光线、环境元素都能正确还原
- **多角色融合可用**：能把2个角色参考图+1个场景图融合成双角色画面
- **速度快**：1步25s vs 连环图生图3步75s

### 3. 多图合成的致命短板

- **角色一致性差**：模型在融合多张图时，角色身份信息被稀释。3张图时角色外观已偏移，4张图时角色种族都变了
- **动作不精确**：模型倾向于生成"静态状态"而非"动态中间态"。prompt说"半起身合电脑"，生成的是"站着看文件"
- **prompt控制力弱**：文字指令在多图输入时权重降低，模型更依赖图片视觉信息而非文字描述

### 4. 与连环图生图的对比

| 维度 | 多图合成（1步） | 连环图生图（3步串行） |
|------|----------------|---------------------|
| 速度 | 25s ✅ | 75s ❌ |
| 角色一致性 | ❌ 2~4分 | ✅ 8~9分 |
| 动作精确性 | ❌ 1~2分 | ✅ 7~9分 |
| 场景一致性 | ✅ 8~9分 | ✅ 8~9分 |
| 多角色融合 | ✅ 可用 | ❌ 不支持 |
| 适用场景 | 多角色场景合成 | 精确动作关键帧 |

## 五、结论与建议

### 不能替代连环图生图

多图合成的角色一致性和动作精确性都达不到关键帧生成的要求。连环图生图仍然是我们生成首尾帧的标准方案。

### 多图合成的新用途

多图合成有一个连环图生图做不到的能力：**多角色场景融合**。把2个角色参考图+1个场景图合成一张双角色画面，这是连环图生图无法实现的。

### 推荐使用方式

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 单角色关键帧生成 | 连环图生图（3步串行） | 角色一致性和动作精确性有保障 |
| 多角色场景合成 | 多图合成（3张：角色A+角色B+场景） | 连环图生图做不到多角色融合 |
| 纯环境空景 | 文生图 | 不需要参考图 |
| 风格迁移/场景重绘 | 图生图（1张参考） | 单图转换效果好 |

### 后续实验方向

1. **多角色场景的prompt优化**：Test B中男性手部位置不当，需要在prompt中更精确描述"伸手挡在身前"而非"伸手触碰"
2. **角色一致性增强**：尝试在prompt中用更强的身份描述词（如"保持与第一张图完全一致的面部特征"）
3. **3张 vs 4张对比**：4张图角色一致性显著下降，3张是上限
4. **多图合成+连环图生图混合流程**：先用多图合成生成双角色场景底图，再用连环图生图生成动作关键帧
