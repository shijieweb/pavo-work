# 📥 teacher/ · 训练协作工作台

> 外部训练员（老师）与项目方的共享工作台。老师提交分析文档，阿编处理/采纳，留言互相交代。

## 📁 结构（只用 3 个东西，不搞复杂）

| 位置 | 用途 |
|---|---|
| `teacher/pending/` | **老师上传区**：分析文档放这里（文件名建议 `日期_主题.md`，如 `2026-08-12_测试计划加强建议.md`） |
| `teacher/done/` | **已处理归档**：阿编处理完/采纳后把文件移到这里 |
| `teacher/BOARD.md` | **留言板**：提交记录（谁/何时/啥/结论）+ 给对方的一句话 |

## 🔄 闭环（就这么简单）

```
老师：把分析文档放进 pending/
  ↓
阿编：读文档 → 有用采纳 / 部分有用部分采纳 / 不采纳（写明原因）
  ↓
阿编：文件移到 done/ + BOARD.md 记录结论 + 留言
  ↓
老师：看 BOARD.md 知道结果，按留言继续
```
