# Pavo-Work · AI 短剧自动化创作工作台

> 全云 API 驱动的 AI 短剧生产流水线：**小说 → 需求卡 → 大纲分镜 → 角色资产 → 关键帧 → 分镜视频 → 合成成片**，一站式商用级创作工具。

## 🎯 项目定位

面向**短剧创作者与 MCN** 的 AI 生产工具：输入一段小说或创意，自动产出竖屏/横屏短剧成片（单集 1-3 分钟），角色视觉一致性由**关键帧绑定管线**保证（首帧身份 SSIM 0.97），支持商用出片（720p/1080p + AI 生成标识合规烧录 + 字幕/BGM/转场）。

## ✨ 核心能力

| 模块 | 能力 | 技术 |
|---|---|---|
| ① 创意·需求卡 | 小说/主题 → AI 需求卡（类型/时长/角色/视觉风格） | agnes-2.5-flash |
| ② 大纲与分镜 | Thinking 深度模式拆解分镜，场景类型自动识别（动作/独白/对话/群戏） | agnes-2.5-flash |
| ③ 资产设计 | 角色锚点图（全片复用锁脸）/ 场景参考图 | agnes-image-2.1-flash |
| ④ 分镜校准·关键帧 | 全首尾针管线：同角色链式尾帧 + 角色锚点 + 场景图兜底 | agnes-video-v2.0 |
| ⑤ 分镜视频 | 图生视频 + 原生中文音画同步（口型帧级匹配） | agnes-video-v2.0 |
| ⑥ 合并成片 | 转场 + 字幕 + BGM + AI 标识 + **客观质检**（黑场/静音/静帧） | ffmpeg |

**质量保障闭环**：身份质检（SFace 人脸比对）→ AI 4 维诊断（AGNES）→ 客观质检（ffmpeg）→ 标记满意 → 合成。

## 🏗️ 架构

```
studio.html (Vue3 工作台)  ← 8777 server.py（生成编排/任务队列）
        ↑ 统一门户
agnes_proxy.py (8787)  ← 老板唯一入口（控制台 + 调试台 + 反向代理）
        ↑
shared_board (8788 任务看板)   AGNES-AI 全云 API（图/视频/文本）
```

- **生成层全云 API**：AGNES-AI（VIP 视频额度 + 免费测试 key 双模式）、MiniMax（可控配音）
- **编排剪辑本地脚本**：ffmpeg 合成、SFace 人脸质检——不依赖单一商业 SaaS
- **任务队列**：批量生成并发 + 限速冷却 + 幂等跳过 + 失败重试

## 🚀 快速开始

```bash
# 1. 配置密钥（AGNES_API_KEY 等，见 .env.example）
cp short_drama_workflow/.env.example short_drama_workflow/.env

# 2. 启动工作台（真实模式，消耗 API 额度）
REAL=1 python short_drama_workflow/html_prototype/server.py
# 打开 http://127.0.0.1:8777/studio

# 3. 统一门户（推荐入口）
python agnes_proxy.py
# 打开 http://127.0.0.1:8787
```

**生成档位**：设置模块可切 测试 480p（快速迭代，免费 key）/ 正式 720p（商用出片）+ 画幅 竖屏 9:16 / 横屏 16:9。
