# 分析师留言 #5 · UI 友好度研究报告（三界面体检）

- **投递时间**：2026-08-13 19:02 ｜ 分析师
- **优先级**：研究结论（给 UI 改进参考；不阻塞 T-07 在途任务）

## 结论
门户最优、看板功能全但有 3 处友好度硬伤、工作台专业但信息密度高。**建议先修看板 3 处硬伤**（小改、体验提升大）。

## 界面一 · 门户 hub（8787 根路径）—— ⭐⭐⭐ 最优
- 实时状态栏（三服务在线/离线 + 更新间隔）、卡片式入口（图标+说明+标签+端口+状态徽章）、服务离线置灰 + **一键自启按钮** + 启动命令提示（自愈）、项目切换器、快捷操作、页脚"怎么选"引导（拿不准参数→调试台；分镜已定→工作台流水线）、移动端适配、手机经 8787 /board 直达看板。
- **无需大改**。可选：加"最近操作"一栏（锦上添花）。

## 界面二 · 看板 board（8788 /board）—— ⭐⭐ 功能全，3 处硬伤
### P0 硬伤（建议本轮修）
1. **详情入口隐蔽**：卡片点击=展开子任务；看详情要**双击（桌面）/长按（手机）**，无任何提示。"详情（长按卡片看这里）"提示藏在抽屉里=引导倒置。
   - 建议：卡片加显式"详情"按钮；或桌面单击=详情、展开改点箭头（二选一）。
2. **无整体进度概览**：只有任务树，一眼看不出"几个进行中/几个完成"。
   - 建议：顶部加进度条（`X 进行中 · Y 待验证 · Z 已完成 / 总数`）。
3. **删除按钮过显眼**：红色大字"删除此任务及子任务"紧挨保存，误触风险高（已有 confirm 但视觉太强）。
   - 建议：弱化为次级按钮（ghost/danger 小字）或移到底部单独一行。

### P1 建议
4. 状态中文化（**T-07 已覆盖**，无需另做）。
5. 支持按状态筛选（进行中/待办/完成…），任务多时定位快。
6. 错误提示从 `alert` 弹窗改为页面内 toast（体验统一、不打断）。

### P2 可选
7. 操作日志 20 条→可加载更多；任务卡片显示子任务数。

## 界面三 · 工作台 studio（8777）—— 🟡 专业但重
- 多步向导结构（①提供创意→②剧本大纲→③资产设计→④分镜校准·关键帧·首尾针→⑤分镜视觉·拆解精控→⑥设置·提示词库→⑦合并成片）**流程清晰**；placeholder 全是实例（"例：05后实习生林小满…"）；按钮语义明确（采纳/生成/标记满意/返工/合并/夜间批量流水线）。
- 目标用户=老板+阿编，学习成本高可接受。**可选**：高密度面板做折叠/分组；移动端主要靠 8787 门户/看板即可，不强求。

## 建议落地

- **后续**：P1 筛选/toast 可开小卡；studio 折叠为可选。
