## 一、视图设计（参考范式）

1. **泳道视图（主视图）**：按 5 态中文分组列 `待办 | 进行中 | 待验证 | 已验证 | 完成`（+ `阻塞` 旁路列），列可横向滚动（`overflow-x:auto`）。
2. **统计条 + 列计数**（参考形态）：`总计 X · 进行中 Y · 待验证 Z · 阻塞 W · 完成 V`；每列头部显示计数徽章。
3. **暗色/亮色切换**：CSS 变量（`:root` / `.dark`）+ 🌙 按钮 + `localStorage` 持久化（参考 kanban.html 实现思想，~30 行）。
4. **toast**：保存成功/失败/刷新反馈用 toast（替代 alert），底部居中淡入淡出。
5. **卡片**：标题 + 优先级徽章 + 状态色边条 + 作者/更新时间 + **子任务计数**；有子任务显示可展开（泳道内嵌或 drawer 内）。
6. **功能融合（参考看板功能 · 纯前端 A 类）**：
   ① **筛选**：按 状态 / 优先级 / 作者 快速过滤（参考 filters 栏形态：按钮组 active 高亮）；
   ② **完成时间戳**：done 卡片显示完成时间徽章（用 `updated` 近似）；
   ③ **flash 高亮定位**：依赖/关联标签点击滚动定位 + 闪烁高亮（参考 `scrollToCard` 实现）；
   ④ **进度条**：留字段位（T-09 加 `progress` 后启用，本卡不显示）。
7. **指导留言栏（新增 · 老板 22:08 收尾清单闭环）**：看板内展示**远程指导留言**（`/ext/notes` 数据）——按项目过滤、最新置顶；本地 8788 与外部 8787 均可见；样式复用操作日志区块（可折叠）。数据源：`GET /api/ext/notes?project_id=N`（T-05 已建 notes 表）。

### 6.2 组件样式（照参考还原）
| 组件 | 样式要点 |
|---|---|
| 卡片 | 圆角 8、1px 边框、`--shadow`；**hover 上浮 -1px + `--shadow-lg`**；标题 14px/600、ID 11px/600 灰、meta 12px 灰 |

| 统计条 | 13px 灰字、数字加粗；`总计/进行中/待验证/阻塞/完成` |
| toast | 底部居中、深底白字、圆角 8、淡入淡出（2s） |
| blocked | 卡片 **2px 红边 + border pulse 动画**；阻塞原因浅红底标签 |
| 优先级徽章 | 色字 + 浅底、10px、圆角 4 |
| 依赖/子任务标签 | 蓝底紫字圆角 3、hover 下划线；点击 **flash 高亮定位** |
| 头像（如用） | 18px 圆形、角色色（PM 紫/FE 蓝/BE 橙/QA 绿） |
| 空态 | 居中灰字 13px |
| 响应式 | 宽屏多列（5 态+阻塞，**横向滚动优先**）；<600px 单列 |

### 6.3 我们的定制（保留参考质感，适配我们的数据）
- 状态色沿用我们的语义：待办灰/进行中蓝/阻塞红/完成绿 + **新态 待验证=amber、已验证=purple**。
- 列 = 5 态中文 + 阻塞（参考是 4 列，我们 6 列场景横向滚动）。
- 卡片 meta = 作者 + 更新时间（参考是负责人+截止）；**子任务计数徽章**。
- 顶部栏 = 我们的控件：项目切换/建项目/改归属/复制派单/自动刷新开关/手动刷新。
- 暗色切换：`.dark` 类 + `localStorage('kanban-dark')`（照参考）。
