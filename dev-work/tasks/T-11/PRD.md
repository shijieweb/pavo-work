## 一、功能清单（要做哪些功能点，逐条）

- F1 **里程碑数据模型**：新增 `milestones` 表（id / project_id / stage_key / stage_name / stage_order / status / created_at）+ `tasks` 表加 `milestone_id` 列（可空）。
- F2 **自动初始化**：项目加载/创建时，若该 project 无 milestones，自动插入 7 个默认阶段（幂等）。
- F3 **里程碑数据接口**：`GET /api/projects/<pid>/milestones` 返回 7 阶段（含每阶段任务计数 + 完成率）；`PUT /api/milestones/<mid>` 更新阶段 status。
- F4 **任务挂接阶段**：任务创建/更新接受 `milestone_id`；抽屉新增"阶段"下拉选择器（7 阶段 + 无）；任务卡片显示所属阶段徽章。
- F5 **阶段视图 UI**：新增里程碑面板，渲染 7 阶段流水线（顺序 + 状态配色 + 进度条 + 任务计数），实时刷新。
- F6 **阶段进度聚合**：每阶段显示 已完成数/总数 + 进度条；整体流水线完成率在面板顶部展示。

## 四、边界与禁止项

- 不改：`agnes_proxy.py` / `route_registry.json` / 任何 `gen_video`/`build_variants`/关键帧/`data_uri` 链路（本次纯看板功能，不触生成逻辑）。
- 禁止：调用 `gen_video` / 烧 VIP / 改无关文件 / 删字段破坏旧数据 / 改 `agnes_proxy.py`。
- 已知坑（开发必须处理）：
  1. 后端每次 GET 实时读 `index.html`，**前端改动无需重启即生效**；但 `server.py` 改动需**重启 8788**（见运行手册铁律）。
  2. **双入口**：8788 直连 与 8787 `/board` 网关（接口经 `/board/api/` 反代）都要验证一致。
  3. 迁移必须幂等：用 `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE ... ADD COLUMN` 前先查列是否存在（`PRAGMA table_info`），避免重复执行报错。
  4. 默认 7 阶段顺序固定，文案：**选题 / 剧本 / 分镜 / 生成 / 配音 / 剪辑 / 发布**。
  5. 任务计数聚合要排除已删除任务（如有软删除口径）；done 判定沿用现有"完成"态口径（与 T-09/T-10 一致）。
  6. 白名单：新接口须登记进 server.py 白名单（参考 T-20260813-02 注册表驱动做法），且 `agnes_proxy` 网关前缀须覆盖（若走 `/board/api/`）。
