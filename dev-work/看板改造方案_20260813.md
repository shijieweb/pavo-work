## 一、外部指导 API 设计（远程指导角色用 · 无鉴权）

### 1.1 背景
远程指导角色（不在本机环境的 AI/机器，如老师/教练/远程主理人）需经网络读取看板了解进度、并留指导意见。**按老板指令：本设计不引入鉴权**（统一鉴权后置）。

### 1.2 访问路径（走 8787 统一网关，对外唯一口）
```
远程机器 ──> http://agnes.owen1.de5.net/ext/...  ──> 8787 网关 ──> board(8788) /api/ext/*
```
- 网关 `agnes_proxy.py` 加 `/ext/` 前缀白名单（转发到 8788，改写：`/ext/` → `/api/ext/`）。
- board `server.py` 新增 `/api/ext/*` 端点（**无 token**，只读 + 留言）。
- ⚠️ **鉴权处理（v2）**：现有 8787 `PORTAL_TOKEN` 闸（T-20260813-03）**改为默认关闭**（`PORTAL_TOKEN_ENABLED=0` 开关，代码保留）；`/ext/*` 无鉴权直达。未来统一鉴权层一次性覆盖全部入口（含门户 /studio /api/* /ext/*）。

### 1.3 端点清单
| 方法 | 端点 | 说明 |
|---|---|---|
| GET | `/ext/status` | 总览：全部项目 + 在途任务 + 最近审计 8 条（远程角色一眼看全局） |
| GET | `/ext/projects` | 项目列表（id/name/owner/created） |
| GET | `/ext/tasks?project_id=N` | 某项目任务树（status/priority/detail） |
| GET | `/ext/audit?project_id=N` | 操作日志 |
| GET | `/ext/presence` | 在线状态 |
| POST | `/ext/notes` | 远程指导留言：`{"project_id":19,"text":"..."}` 写看板，前端「指导留言」栏展示，审计记 `agent=远程指导` |

### 1.4 鉴权策略（老板定）
- **本设计不引入鉴权**；任务增删改仍走原写接口（本地信任）。
- 安全风险登记（不阻塞）：当前公网暴露面 = `/studio`（可改 projects 文件）+ `/api/*` + `/ext/*` 全开放——见「四、风险登记」。统一鉴权层挂账后续。
