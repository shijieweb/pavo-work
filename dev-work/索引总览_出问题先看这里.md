## 一、铁律速查（出问题先对这几条）

1. **派活必须团队模式**：TeamCreate 建团 → 团内规范 spawn → SendMessage 异步派活；**禁用 Agent 工具直接派**（当前环境直接派=静默空返回）。
2. **两道分离**：开发推「待验证」即停（无 done 权）；测试**独立验收**推「已验证」（不修 bug）；主理人才标「完成」。**任何人无权跳过测试角色**。
3. **先验证再宣告**：空/缺/旧 artifact = 未完成。主会话读盘核产（judge 判定矩阵），不靠角色自报。
4. **改代码前 `git commit before:`**；改 server.py / agnes_proxy.py 后**干净重启**（杀残留 PID 核实新 PID）。
5. **密钥永不进代码/日志**；测试一律免费 KEY L1（`_pool.use_test()`），禁烧 VIP。
6. **做少=忘少**：单一真实项目；board=实时进度真相，current_state=验收证据档案。
7. **迁移/删除/大改前必备份**（db/项目/代码快照）；删任务/项目先确认（board 删除会连删子任务）。

## 四、正确派活 5 步（速查副本 · **以交接文档 §3 / 运营手册 §3.6 为单一事实源**，改动只改那边）

1. **注册专家团**：`search_plugins` 搜 SoftwareCompany → `suggest_plugin_install` 发卡片 → **老板点确认** → 专家进列表（software-* 角色才可用）。
2. **建常驻班底**：`TeamCreate software-shortdrama`（主理人亲自建，跨任务复用，不每次删）。
3. **规范 spawn**：`Agent(team_name=..., name=software-engineer / software-qa-engineer, subagent_type=同值)`，禁自创名、禁无 team_name。
4. **异步派活**：`SendMessage` 给成员（后台跑、消息回传），**绝不用"等返回"阻塞姿势**；prompt 必含「角色分工铁律」。
5. **验证 + 收尾**：回报后主会话读盘核产（judge：空/缺/旧=打回）；真跑/外网/长时主会话亲自做；闭环后 shutdown + `TeamDelete`。
