## 基本信息

- **格式**：`[BUG][S<严重度>|P<业务级>] 一句话现象 (AC-<编号>)`
- **严重度 S**：S1致命 / S2严重 / S3一般 / S4轻微（测试定）
- **业务优先级 P**：P0阻断 / P1高 / P2中 / P3低（阿编定）
- **ac_ref**：指回 PRD 的某条 AC（无 AC 可指 → 走变更闸2 或不是 bug）
- **生命周期**：新建→已定级→已指派→修复中→待验证→待回归→已验证→已关闭；复发「重新打开」
