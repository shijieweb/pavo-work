## 1. 镜头拆分（导演思维）★ 重点

**核心认知**：首尾帧必须**同场景 / 同光效 / 同机位**才能过渡，否则 AI 无法理解 → 必须**拆成两个镜头**。

- **实证**：v16 空景微动 + v17 人物微动，两镜场景完全一致（同街道 / 星空 / 机位）才能拼接成完整运镜（中景 → 正面特写）。
- **反面教材**：昏暗空景 → 正面近景 = 两个镜头，不能一镜硬过渡。
- **纯空景注意**：prompt 写 `no people` AGNES 不理会（默认塞人物）——纯空景需要 **i2v 单图 + 运动 prompt**，而不是 keyframes 双图。
- **代码落地**：`_split_long_shots`(server.py)
  - 触发：运镜镜（camera 含推 / 拉 / 摇 / 移 / 跟）+ `duration > 6s` → 拆 2~3 个 3-4s 短镜。
  - 每镜：同场景同机位单动作；首尾帧提示词物理规律派生（首镜=起点 / 末镜=终点 / 中镜=过渡）。
  - 不拆：台词镜 / UI 镜。
  - 单测 6/6 PASS；重跑分镜验证 10 镜 → 14 镜（5 个运镜长镜拆成短镜链）。
- **规则已进**：`STORYBOARD_SYS` 8.6（拆镜）/ 8.7（短镜优先）。

---

## 2. 首尾帧物理规律

**核心**：图1 状态 → 图2 状态必须**物理 / 空间可衔接**。

- **v18 真空景**：文生图 + i2i 微变 → 雾气渐浓、灯光微变、全程真空景（验证物理 10 / 连贯 9）。
- **v19 人物走近**：远景小 1/3 → 中近景；同机位同场景，人物明显变大、背景被切掉上半、机位推近（人物 9 / 连贯 8 / 物理 9 / 首尾 8）。
- **v18+v19 拼接** = 完美运镜：空镜建立环境 → 人物走近。
- **反面**：prompt 写"走近变大"但 i2i 默认生成同大小全身图 → 图和文矛盾，AI 困惑。

---

## 3. prompt-图一致性

**核心**：prompt 描述的差异，必须与实际首尾帧的**视觉差异吻合**（图和文矛盾，AI 只按图生成）。

- **规律**：i2i **默认生成同大小全身图**，需强约束（"人物占画面 60-70% 中近景"）才能得到真正走近。
- **操作纪律**：每生成首尾帧后**用 AGNES 视觉对比实际差异**，prompt 描述与图一致。
- **经验**：之前 prompt 只描述首尾帧画面、没描述中间运动(Animate)与稳定约束(Keep stable) → AGNES 只能猜 → 跳变。

---

## 4. Animate 双要素

**核心模板**：`Animate(什么在动)` + `Keep stable(什么不动)`，**两要素必填**。

- **闭环 bug（实锤）**：生产管线 reference 分支只拼 Keep stable（"while keeping face and outfit consistent"），**缺 Animate** → AGNES 生成近乎定格，质检 fail（连贯 6 / 首尾 5 / 原因"四帧几乎完全相同"）。
- **修复**：加 `_animate_clause(shot)` 按动作词自动生成"什么在动"（有动作=人物自然运动；无动作=环境微动兜底），reference + text2video 两分支都接入。
- **修复后**：镜1 重渲 verdict PASS + 4 维全 9 + face 10 + quality 10 + 镜头连续无定格（0s 远景 → 5.8s 近景抬头，自然"人物从远处走入"）。
- **规则**：双向要素必填；中文格式更细腻；生产过渡句改中文版。

---

## 5. 时长匹配复杂度

- **短镜优先 3-4s**（81 帧）；长台词 ≤8s；**绝不超 12s**（8.7）。
- `_ensure_duration`：变化点（动作 + 运运去重）→ 3/4/5/7/10s 表；模型给少了自动补足（≤12s）。
- 单镜内同场景 / 同光效 / 同机位，仅姿态 / 景别渐变；差异大 → 拆多镜链式衔接。

## 6. 质检体系（7 项 + 升级）

| **smart 抽帧** | 首帧 0s 必抽 + 尾帧 dur-0.2s 必抽 + 中段 0.5s 间隔（替换均匀抽帧——旧法漏首尾） | 均匀抽帧(0.4/1.1/1.8/2.5s) 首尾根本没抽到 |
| **prompt_frame_match** | 提示词开场场景 vs 首帧 + 结束状态 vs 尾帧，AGNES 视觉判定 match/warn/fail | 正例 v19 pass；负例（沙滩/红礼服 vs 夜城/白衬衫男）fail+场景冲突/人物缺失/服装不符——自动抓 prompt-图不一致 |

## 7. 生产管线 bug + 自动固化

- **seed 签名 bug（实锤）**：`create_video() got unexpected keyword seed`——昨晚只改 server.py 调用点加了 seed，但 `agnes_client.create_video` 别名签名没加 seed（单测 mock 了自己的 fake 函数所以没暴露）。修复：create_video 转发 seed，重启 8777。
  - **铁律**：改 API 签名必须同时改真实函数（不能用 mock 单测代替）；seed 全链路（`_submit_video → create_video → server 调用点`）。
- **自动固化流水线 A+B 阶段**：
  - A：实验(learn 块) → `auto_learn.py` 提取（过滤 runs≥2 高置信 / 哈希去重 / 冲突检测 vs prompt_library+经验库）→ 产出 `learn_output/固化建议_*.json`。**提取器绝不写源文件**。
  - B：`apply_fix.py`（半自动应用器）：approved 条目 → 安全层应用（08 经验库追加 / prompt_library optimize 追加，白名单绝不动逻辑代码）→ git 快照 → 去重二次确认 → 单测校验 → 失败备份回滚。
  - 闭环：实验 → 提取 → 人工闸门(老板审) → 应用。
- **看板参数丢失**：手动写 exp 数据必须带全 params（prompt/prompt_cn/seed/negative/size/keyframes…），脚本生成自动带全；建议包/实验数据重建用 `build_variants` 兜底。

## 8. 运维脚本 PowerShell 坑（附带）

- **规律**：PowerShell 函数 `return $arr`（数组）会被**管道枚举拆包**；当只有 1 个元素时，调用方 `$x = Func` 拿到的是**裸标量对象**（不是数组），其 `.Count` 为 `$null`（PS5.1）。任何依赖 `$x.Count -gt 0` / `$x.Count -eq 0` 的分支判断会失效（恒 False / 恒走 else）。
- **触发**：`Get-CimInstance Win32_Process -Filter ...` 单命中时函数返回单对象，最易中招（clean_restart 不杀进程反派生双进程即此坑）。
- **修复范式**：① 函数内 `return ,$arr`（逗号包裹，强制返回单元素数组）；② 调用方 `$x = @(Func)` 双重保险。

---

## 9. 可复用铁律（给后续接手者）

1. **实测 > 推断**：隔离探针在本地变量查 `.Count` 会误判正常，必须在"经函数 return 拆包后"的调用方上下文或直接实跑验证行为。
2. **改 API 签名必须同步改真实函数**，mock 单测不能替代端到端。
3. **单镜诊断传单镜**，绝不传完整 10 镜 storyboard。
4. **每生成首尾帧看图实际差异**，prompt 与图一致；i2i 默认同大小，需强约束得真变化。
5. **Animate 双要素必填**（动 + 不动），reference 分支不能只拼 Keep stable。
6. **拆镜按导演思维**：同场景同机位才一镜，否则拆；纯空景用 i2v 单图 + 运动 prompt。
7. **质检 smart 抽帧 + prompt_frame_match** 是抓"prompt-图不一致"的利器，必须进诊断闭环。
