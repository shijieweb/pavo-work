# 05 · 测试指南（改完必读，老板定：真实测试 + 三轮自测）

## 测试纪律（最高优先级）
1. **改完即测，禁止等老板发现问题**：语法 → 端点 curl（真实 AGNES）→ 干净重启 → Playwright 操控 → 真实 1 镜。
2. **真实优先**：老板明确"不能只用模拟测试"，真实接口（AGNES 图/文/视频）+ UI 真实操控，额度烧得起（500s/天 + 备用 key）。
3. **最少三轮自测**：功能改动完成后跑 ≥3 轮，无 flaky 才算过。
4. **测试勿污染真实项目**：PUT 真实项目 meta/spec 会覆盖数据；用临时测试项目或测后精确恢复。曾多次踩坑（QA 数据写进老板项目）。
5. **ACTIVE 保护**：`GET /api/spec?project=` 会切 ACTIVE！QA 脚本开头锁定测试项目，PUT 断言落点，防误写老板项目。

## 环境
- Playwright（Python 版可用）：`python -c "from playwright.sync_api import sync_playwright"`
- 走 8787 门户（老板同路径）：`BASE=http://127.0.0.1:8787`
- Vue3 实例路径（驱动/读取组件状态）：`document.querySelector('#app').__vue_app__._container._vnode.component.proxy`（**不是 #app.__vueParentComponent**）
- Playwright evaluate 参数用 `p => (proxy).x = p` 形式（箭头函数拿不到 arguments）

## 标准回归流程（新功能）
```
1. 语法：py_compile server.py + node --check 提取的 studio.html JS
2. 内存单测：纯逻辑函数（分类/翻译/尺寸/清洗）
3. 干净重启 8777（杀全部 server.py 实例，确认端口释放）
4. curl 端点：真实调用（含 AGNES），断言返回
5. Playwright：真实浏览器操控（点按钮/改参数/轮询状态），断言 DOM+数据
6. 真实 1 镜：关键帧或视频生成 1 镜，验证链路（含 ffprobe 尺寸）
7. 发布：python scripts/diag/publish.py（fast 13 项 + 提交推送）
8. 清理：删测试项目（含注册表）/临时脚本/QA 痕迹；恢复 ACTIVE 到老板项目
```

## 常见坑
- **$set/$delete**：Vue3 已移除，一调用抛 TypeError 中断批量 → 直接赋值。
- **evaluate async**：Playwright evaluate 对 async 函数返回 Promise 会等待，但保险用轮询。
- **f-string 与 JS 花括号冲突**：Playwright 注入 JS 用字符串拼接 + replace 占位。
- **合成后文件时序**：等 loading=false + 文件大小稳定再校验（曾读 8.3MB 中间态误判失败）。
- **按钮文案匹配**：先 grep 实际文案（如"合并全部分镜"非"合成"）。
- **localStorage 草稿干扰**：测试前 clear + reload（旧项目需求卡草稿会让断言误判"生成完成"）。
