## 4. 工程铁律（防复发，改代码必读）

1. **改 server.py 后必须干净重启**：杀全部 server.py 实例（PowerShell `Get-CimInstance Win32_Process` 按 CommandLine 查，勿信 Get-NetTCPConnection 的 PID 0 假象），确认端口释放再起新进程。
2. **新增 /api/* 路由必须同步 agnes_proxy.py 白名单**；改 server.py 路由也核对。
3. **开发必带测试**：语法 → 端点 curl（真实 AGNES）→ 干净重启 → Playwright 操控 → 真实 1 镜。**禁止等老板发现问题**。
4. **测试勿污染真实项目**：PUT 真实项目 meta/spec 会覆盖数据；用临时项目或测后精确恢复。
5. **Vue3 禁用 $set/$delete**（Vue2 方法已移除，曾致批量卡死）；reactive 对象直接赋值。
6. **持久化恢复必须合并默认值**：`Object.assign({...默认}, stored)` + 数组字段 Array.isArray 校验（曾致白屏）。
7. **AGNES 网络**：域名硬编码 4 处（agnes_client.py:39 / agnes_proxy.py:27 / agnes_console.html:525 / 文档）；`.com` 直连被出口防火墙重置，用国内 `.cn` 直连；本地代理 127.0.0.1:10808 起后 HTTPS_PROXY 恢复。
8. **额度**：AGNES VIP 500s/天按时长计（低分辨率不省额度只快）；2 把限速 key LRU 轮换。
9. **长任务安抚**：提交+轮询模式（accepted → status），前端绝不明目等；后台任务每分钟汇报。
