# 04 · 生成管线（提示词工程）

## 分辨率 / 画幅（_video_size 统一入口）
`环境变量 VIDEO_WIDTH/HEIGHT` 覆盖 → `meta.resolution_mode`（test=480×854 / prod=720×1280）→ `meta.aspect_mode`（landscape 交换宽高：854×480 / 1280×720）。
**官方归一化 480p/720p/1080p 档**（实测 480×854→448×832，720×1280→704×1280）。
合成跟随：`do_assemble` 传 `--resolution` 给 assemble.py（测试档合 480×854，1.9MB vs 旧 1080p 9MB）。

## 首尾针链式（全首尾针管线，0810 定）
- **策略判定**：角色 ref（命中 references 键）→ keyframes 锁脸；空镜/场景引用 → reference（场景图单图）；ui → ui 真视频分支。
- **首帧来源链**（0811 更新，运镜优先）：**运镜镜头**（`_is_camera_move`：36 个中英文运镜关键词 + shot.camera_move 手动三态 auto/yes/no）且 `first_frame_prompt` 非空 → **`_gen_camera_start`：场景图/角色锚点作底图 + first_frame_prompt → i2i 生成「运镜起点画面」**（无底图纯文生兜底；本地 rel 自动转 data URI）→ 同场景族+同角色上镜尾帧（链式连贯）→ 角色锚点 → 场景图 → 文生图兜底 `_gen_first_frame_fallback`（含"无行人/无人/空镜"NEG 抑制）。
- **运镜首帧为什么重要**（老板洞察 0811）：提示词"from 门口 push-in to 人物"时，首帧必须是起点画面（门口/过道/空景），否则关键帧动画与 prompt 起点矛盾、运镜感全丢。源头 STORYBOARD_SYS 强制运镜镜头输出 `first_frame_prompt`（起点）+ `last_frame_prompt`（终点）。
- **幂等**：首尾帧已生成且非 force → skipped（8ms 不烧额度）。
- 空镜正确姿势：**绝不能 keyframes**（首尾针缺失→卡片空白+兜底画人）。

## 场景类型（scene_type 源头 + 兜底）
分镜 schema 要求模型输出 `scene_type`；`_classify_scene_type` 规则兜底：独白词→monologue；多人词→dialogue_multi；有台词→dialogue_2；否则 action。
四套电影语法（`_cinema_clause` 注入）：独白=单人中景+失神+慢推柔光+MOUTH_STILL（MiniMax 旁白）；对话=双人同框+对视+戏剧光；动作=默认。

## 视频 prompt 拼装顺序（前后端 finalPrompt 一致）
```
[过渡描述/video_prompt 清洗] + [global_style 清洗] + [身份锁(有 ref)]
+ [稳定句(reference 有 ref): while keeping the face and outfit consistent]
+ [运镜 _camera_clause 中文翻译+去重] + [光线/风格 映射官方词库]
+ [cinema_clause: 景别+情绪+背景锁定+竖屏/横屏构图词]
+ [台词 _speech_clause: 情绪翻译 + 中文语音指令 AUDIO-ONLY]
```
- 清洗 `_clean_video_prompt`：去尺寸词（9:16/16:9/vertical/landscape/portrait）+ 水印文字词（归 negative_prompt 管），保留风格质量词（film grain/8K）。
- `_clean_global_style`：global_style 可能带模型脏词，拼接前清洗。
- 情绪翻译 `_emotion_en` / 前端 `emotionEn`：40+ 中文情绪词 → 英文（未匹配中文→expressive），防中英混杂。
- **尺寸是接口参数（width/height），不是 prompt 文字**（曾 2 个 9:16 重复 bug）。
- 首帧/尾帧图 prompt 用静态帧语法（凝固帧+锐焦+无运动模糊+film-still，末帧 then settling into final pose）。
