# 06 · 排障指南（老板说出问题时）

## 标准流程
```
老板说「出问题了」
  → 先问现象（截图最好，用 read_screenshot.py 识别）
  → 打开 :8787/logs 按时间线找 ERROR/500/前端上报（frontend:error）
  → 定位环节：前端 JS 报错 / 后端 API 500 / AGNES 调用失败 / 数据不一致
  → 修复 → 按 05 测试指南验证
```

## 高频问题速查

| 现象 | 根因 | 处理 |
|---|---|---|
| **HTTP 524** | CF 等 100s 源站无响应——**同步长请求必然触发** | 已改提交+轮询（accepted → status）；若再出现说明还有同步请求没改造 |
| **HTTP 429** | 视频批量超 RPM=5 限流 | 后端已自动退避重试（15/30/45s×3）；重提交失败镜即可 |
| **8787 404 "unknown path"** | 新端点没登记代理白名单（或端点不存在） | grep `agnes_proxy.py` STUDIO_PREFIXES；8777 直连对比 |
| **批量卡住"已 0s"** | 前端请求悬挂 / Vue3 $set 崩溃 / 后端超时 | 查日志请求是否到达后端；grep `$set`；检查 429/网络 |
| **白屏** | 服务端 200 但前端 Vue 运行时错误 | ①v-cloak 隐藏全页=Vue 初始化失败 ②换 vendor/vue.global.dev.js 拿详细报错 ③取 `#app.__vue_app__...render.toString()` 定位 |
| **需求卡/大纲刷新丢失** | 生成后未落盘（旧版）或加载错项目 | 新版生成即自动保存+localStorage 双保险；查 ACTIVE/loadProjects 优先级 |
| **场景/资产中文描述空** | 旧分镜无 cn_prompt 或 style-only 空壳被误判"已有" | ③点「提取全部中文」补全；新分镜 schema 自带 |
| **视频画面与描述不符（出生人）** | 空镜被判 keyframes + 兜底画人 | 空镜必须 reference（场景图）；检查 ref/策略/描述关键词 |
| **成片尺寸不对** | 旧版本合成固定 1080×1920 | 新版合成随档位（--resolution）；重新合成 |
| **git push 静默失败（exit 128 无输出）** | 阿编执行环境沙箱拦截 git smart HTTP 出网（curl 直连 github 却通） | git 出网操作改用非沙箱执行（需确认）；或老板 cmd 手动 `git push` |
| **手机强刷后仍旧版** | 浏览器缓存 | 无痕模式访问；CF no-store 已透传 |

## 日志系统
- 目录：`html_prototype/logs/`，按天滚动（server.log.YYYY-MM-DD），保留 7 天（LOG_KEEP_DAYS）。
- 级别：`LOG_LEVEL` 环境变量（开发 DEBUG 全量 / 正式 WARNING 只记错误且日志页 403）。
- 查看：`:8787/logs`（logs.html：日期/级别/关键词/只看错误/自动刷新）。
- 前端自动上报：JS 错误/资源失败/关键事件 → POST /api/log 落盘（`[frontend:error]`）。
- 密钥永不入日志。

## 常用诊断命令
```
netstat -ano | grep -E ":(8777|8787)" | grep LISTEN          # 端口
PowerShell: Get-CimInstance Win32_Process | where CommandLine -like '*server.py*'   # 查残留进程
curl -s "http://127.0.0.1:8787/api/spec?project={id}"        # 项目数据+meta
curl -s -X POST "http://127.0.0.1:8787/api/generate/status?shot=1"  # 任务状态
ffprobe -v error -show_entries stream=width,height:format=duration -of json final.mp4  # 成片尺寸
```
