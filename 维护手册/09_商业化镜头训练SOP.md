# 09 · 商业化短剧镜头训练 SOP（2026-08-12 老板方法论固化）

> 从 v0-v20 连续 7 轮实验 + 老板导演思维修正中提炼的"一个能用的镜头"完整生产链。
> 覆盖：拆镜/首尾帧/提示词/时长/质检全环节。

## 一、核心认知（血泪总结）

1. **AGNES keyframes = 图片驱动**：90% 问题出在关键帧图本身，不是 prompt。
2. **AI 无法理解它"看不见的关系"**：首尾帧图之间的过渡必须**物理可解释**（同一空间连续动作），否则视频必跳变/闪现。
3. **AGNES 生成有随机性**：单次变体结果不可靠，结论需 runs≥2 或视觉双重验证。

## 二、正确生成链（7 步缺一不可）

```
① 拆镜（导演思维）  单镜内部：同场景 / 同光效 / 同机位
② 首尾帧设计        每镜自己的双帧图，不复用原图
③ 物理规律（图）    图1状态 → 图2状态可衔接（距离缩短/姿态微变/时间推移）
④ prompt-图一致     prompt 描述必须与图实际差异吻合（图和文矛盾 → AI 按图生成）
⑤ Animate 双要素    什么动（Animate）+ 什么不动（Keep stable）
⑥ 时长匹配         变化点多=时长长（≤12s）；少=短（81帧≈3.4s）
⑦ 自动质检          intro_flash + 内部一致 + 尾帧脸型 + 4维诊断
```

## 三、镜头类型配方（已验证）

| 镜头类型 | 首尾帧生成 | 提示词要点 | 时长 | 验证 |
|---|---|---|---|---|
| **空镜建立**（v18） | 文生图真空景 + i2i 微变（no people） | Animate: 雾气/灯光微变；Keep: 无人物 | 81帧 | PASS 物理10 |
| **人物走近**（v19/v20） | 远景小(1/3高) → 中近景（同机位） | Animate: 走近变大；Keep: 服装/背景 | 81帧 | PASS 修复质检后 |
| 对话镜 | 双人锚点 → 说话状态 | 口型同步 + 身份锁 | 121帧 | 待训练 |
| 独白镜 | 人物锚点 → 情绪姿态 | 情绪表演 + 微动 | 81帧 | 待训练 |

## 四、首尾帧图生成规范

1. **空景必须文生图/i2i 明文 "NO people"** —— 复用含人物原图必失败。
2. **人物镜必须 i2i 从锚点衍生** —— 保持背景一致。
3. **强约束景别**：要"走近变大"必须写"人物占画面 60-70% 中近景"，否则 i2i 默认同大小全身图。
4. **生成后看图验证**：AGNES 视觉对比首尾帧差异，确认 prompt 描述与图实际一致。

## 五、提示词模板（官方 Animate 双要素）

```
英文版：
Create a smooth transition from the first keyframe to the second keyframe.
Animate: <什么在动：人物自然动作/呼吸/头发/灯光/环境细节>
Keep stable: <什么不动：面容/发型/服装/机位/场景>，no jumps, no morphing.

中文版（更细腻，实测连贯/物理/首尾高 1-2 分）：
从第一个关键帧到第二个关键帧平滑过渡。
运动：<状态A→状态B + 光效/细节变化>
保持稳定：<面容/服装/场景/机位完全一致>，无跳变无变形。
```

## 六、质检体系（7 项）

| 质检 | 查什么 | 触发 |
|---|---|---|
| 4维诊断 | 连贯/物理/角色/首尾 | AGNES 2.5-flash 抽帧评分 |
| face 客观 | intra_jump 镜内换脸 / cross_drift 跨镜串脸 | face_qc 本地人脸检测 |
| intro_flash | 开头异常闪现（首帧人物特写跳变） | AGNES 视觉抽开头帧 |
| 内部一致 | 视频自身首帧 vs 尾帧（服装/外观变化） | AGNES 视觉 |
| 尾帧脸型 | 尾帧 vs 角色锚点（真实脸型一致性） | AGNES 视觉双图 |
| quality 画质 | 畸形/穿帮/AI 痕迹 | AGNES 视觉 |
| 镜头连贯 | 上镜尾帧 vs 下镜首帧接戏 | AGNES 视觉双图 |

## 七、质检坑（已修，防复发）

1. **单镜诊断必须传"只含当前镜"的 storyboard**！face_consistency 按时间线累计抽帧，传完整 storyboard 会让 scale≈0.067，抽帧点挤在开头 → 人脸误检 intra_jump → face 虚低。已修 training + /api/diagnose。
2. **运镜镜头首帧空景不算服装/脸型不一致**——对比取尾帧/中后段。
3. **face 检测 has_face=False**（haar 320px 对中近景可能漏检）——后续可升级 yunet deep。

## 八、实验方法论（训练营）

```
1. 基准变体（现状写法）对照 → 量化提升幅度
2. 单变量原则：一次只动一个因素，归因清楚
3. 假设驱动：每个变体有理论依据（官方文档/已知机制）
4. runs≥2 重复（AGNES 随机性）→ 多数投票定论
5. 复验：规则用同类型新样本验证（防过拟合）
6. 看板透明：数据/视频/6要素卡片全可见，老板审查采纳
7. 审批门：候选 → 老板看板点采纳 → 才固化进工作台
```
