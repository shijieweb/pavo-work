# 03 · 数据契约

## meta.json（项目元数据，PUT /api/meta 浅合并）

| 字段 | 类型 | 说明 |
|---|---|---|
| `source_mode` | str | novel / theme（①入口） |
| `source_text` / `novel` | str | 已提交小说原文 |
| `req_card` | obj | 需求卡：title/genre/duration/aspect/era_region/style/shot_count/characters[] |
| `outline` | obj | 大纲：title/characters[]/scenes[]/episodes[] |
| `visual_style` | obj | locked/cn_text/en_keywords[]/confirmed |
| `workspace_state` | obj | 跨设备 UI 状态（见下） |
| `resolution_mode` | str | test(480p 默认) / prod(720p) |
| `aspect_mode` | str | portrait(9:16 默认) / landscape(16:9) |

### workspace_state（A 类·服务端，跨设备）
`active_module / confirmed_steps / source_mode / asset_tab / asset_detail_open / mat_filter / selected_shot / merge_transition`
恢复时逐字段校验合法值；**改任何 A 类状态都要同步 saveWorkstate 与 loadSpec 恢复段**。

### localStorage `studio:ui:{pid}`（B 类·本机草稿）
`novelInput / themeInput / agentOpen / showLog / faceOpen / reqCard / outlineData / visualStyle`
saveUiLocal/loadUiLocal；**novelInput 双来源**：服务端 meta.source_text（已提交）+ 草稿优先。

## storyboard.json（SPEC，PUT /api/spec 全量）

| 字段 | 说明 |
|---|---|
| `global_style` | 全局风格（清洗后：无尺寸词；模型输出可能带 16:9 landscape 脏词） |
| `resolution` | 模型输出宽高（**仅展示，实际生成/合成按档位**） |
| `voice_roles` | 角色→MiniMax 音色 |
| `references{}` | 角色锚点：img_prompt/identity_token/remote_url/cn_prompt |
| `scenes[] / props[]` | **规范为数组**（load_spec 自动 dict→list；模型偶发输出 dict 会崩前端） |
| `shots[]` | 见下 |

### shot 关键字段
`id / ref / scene_key / gen_strategy(keyframes|reference|ui) / scene_type(action|monologue|dialogue_2|dialogue_multi) / cn_story / video_prompt / subtitle / emotion / camera / lighting / style / negative_prompt / first_frame_prompt / last_frame_prompt / asset_frame_start / asset_frame_end / asset_video / video_size / video_seconds / diagnosis / face_identity / satisfied / transition_in / transition_out`

- `gen_strategy` 迁移规则（load_spec）：角色 ref（在 references 键内）→keyframes；空镜/场景引用→reference；ui→ui。
- `scene_type` 兜底：源头覆盖有波动，load_spec 缺失/非法时 `_classify_scene_type` 规则兜底写回。
- `video_size/video_seconds`：ffprobe 回读真实成片（提交 720×1280 → 实际 704×1280；480×854 → 448×832）。
- `diagnosis`：`/api/diagnose` 写回 `{scores{continuity,physical,character,first_last}, verdict, summary}`。
- `face_identity`：`/api/faceqc` 写回每镜身份分。

## 关键读写注意
- **防清零拦截**：PUT /api/spec 内存 0 镜不覆盖磁盘有镜数据（曾防大事故）。
- **测试勿污染**：PUT 真实项目会覆盖 meta.json（曾把测试 req_card 写进老板项目）。
- **持久化恢复合并默认值**：`Object.assign({...默认}, stored)` + `Array.isArray` 校验（曾致白屏）。

## experiments_data/exp_*.json（镜头训练实验数据 · 看板数据源）
> 由 `short_drama_workflow/scripts/diag/prompt_training.py` 生成，`http://127.0.0.1:8787/training` 展示。
> 每次实验一个文件，最新在上（文件名 exp_YYYYMMDD_HHMMSS.json）。**手动写必须带全 params（见坑）**。

### 顶层字段
| 字段 | 说明 |
|---|---|
| `id` | 实验 ID（=文件名去前缀，如 0812_1502） |
| `type` | 实验主题（如 运镜镜头-物理规律首尾帧验证） |
| `project / shot` | 实验目标项目 ID 与镜号 |
| `created` | ISO 时间 |
| `status` | running / done / candidate / adopted / rejected（看板状态流） |
| `candidate` | 标记的候选赢家变体（待老板审查） |
| `key_finding / candidate_note` | 关键结论 / 候选说明 |
| `rules_draft[]` | 实验级规则草案（可选，人工或自动填充） |
| `variants[]` | 变体数组（见下） |

### variants[]. 关键字段
| 字段 | 说明 |
|---|---|
| `name` | 变体名（v0/v14/v19…，看板排序键） |
| `verdict` | pass / fail / warn（AGNES 4 维诊断综合） |
| `hyp` | 变体假设（为什么这么试） |
| `diagnosis` | 4 维评分 `{continuity,physical,character,first_last,face,quality}`（smart 抽帧） |
| `intro_flash / internal_consistency / identity_review` | 独立质检项 verdict |
| `prompt_frame_match` | `{overall, opening{verdict,issues}, ending{verdict,issues}}` 提示词-帧匹配 |
| `video` | **相对 TRAIN_VIDEO(=scripts/diag/experiments) 的完整路径**，如 `ep_0811_145935/shot1/v19/shot1.mp4`（只存 basename 看板 404） |
| `params` | 生成参数（见下） |
| `learn` | 【自动固化流水线】结构化经验块（见下） |

### variants[].params 完整字段（手动写必须全带）
`prompt`（最终合成提示词·提交原文）/ `prompt_cn`（中文翻译）/ `keyframes[]`（首尾帧角色标注）/ `images`（图数）/ `num_frames` / `size` / `frame_rate` / `mode` / `model` / `negative` / `seed` / `duration_s`

### variants[].learn（0812 自动固化流水线新增）
```
learn = {
  rules_draft: ["【v19 已验证配方】镜B物理走近：远景→中近景（证据: 4维全>=7+...）"],
  evidence: {variant, verdict, scores{4维+face+quality}, intro_flash,
             internal_consistency, prompt_frame_match, identity,
             num_frames, frame_rate, duration_s, size, seed, negative},
  pass_reason: "4维全>=7+intro_flash pass(开头不闪)+..."
}
```
- `_learn_block()`（prompt_training.py）自动生成，pass 变体必有；auto_learn.py 只读提取。
- 生成参数规范：num_frames 走 `_snap_nf`（8n+1，≤441）；frame_rate 24/30；negative 官方词必传；seed 固定可复现。

### 实验数据坑（08 经验库同源）
- **手动重建 exp 必须带全 params**（prompt/keyframes/seed/negative/size…），缺字段看板显示不全（0812 事故）。
- 重建优先用模板 `build_variants(shot, ref, template)` 兜底生成，不手写。
- 清理备份在 `_archive_20260812_experiments/`（勿删，可恢复对比）。
